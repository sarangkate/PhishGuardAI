# User Guide

1. Sign in to PhishGuardAI with Google.
2. Choose **Authorize Gmail Access** and review the requested read-only permission.
3. Select an email from the inbox.
4. Wait while the application loads the email and performs the security check.
5. Review the Trust result, Sender Analysis, Link Analysis, warning signs, recommended action and security awareness information.
6. Do not use the application result as an absolute guarantee. A high trust score means no strong indicators were detected by the current analysis.
7. Suspicious links are not opened automatically.
8. Use Settings to disconnect Gmail or manage local analysis-history preferences.
